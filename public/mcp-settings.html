Finish in ChatGPT web

  1. Enable Developer mode in ChatGPT Settings → Security and login, if your account or workspace allows it.
  2. In ChatGPT Plugins, add a connection using the MCP server URL above, select OAuth and enter the client ID and secret.
  3. Sign in to Briareus and approve access to the selected projects.
  4. Add Briareus to a chat and ask it to list your projects or perform an action.

Starting work can incur agent costs, and some actions change GitHub or delete sessions. Revoke a connection here to stop its access.
