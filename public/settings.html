Memory

Every clone slot in the workspace pool. A slot is claimed for as long as the session in it stays open; the actions only work on idle ones. Reset setup forgets which installs already ran, so the next session runs them all again. Clean also removes vendor/ and node_modules/. Nothing else is ever deleted.
